Сладкие сны - сервис бронирования номеров (статичная версия для GitHub Pages)

Страницы:
index.html - каталог номеров с фильтром по категориям
order.html - бронирование номера, календарь с занятыми датами
login.html - вход администратора
admin.html - список заявок, кнопки "Одобрить" и "Удалить"

Администратор: логин hotel123, пароль adminHotel

Особенность: сайт работает без сервера. Заявки хранятся в localStorage браузера.
Версия с PHP и MySQL лежит в отдельном репозитории.
